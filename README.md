# Chef Vini — O Natal à Mesa

Landing page em React + TypeScript (Vinext/Vite) para uma proposta de Kit de Ceia de Natal.

## Rodar localmente

Requer Node.js 22.13 ou superior.

1. Execute `npm install` na pasta do projeto.
2. Execute `npm run dev`.
3. Abra o endereço local informado no terminal.

Para gerar a versão de produção: `npm run build`.

## Personalizar

- Conteúdo, menu e WhatsApp: `app/page.tsx`.
- Cores, tipografia e animações: `app/globals.css`.
- Título e descrição: `app/layout.tsx`.
- Imagens: `public/`.

O WhatsApp configurado é +55 47 99912-1977. O site abre uma mensagem para o visitante revisar e enviar; não confirma reservas ou pagamentos. Cardápio, preço, pesos, prazos e logística precisam ser confirmados pelo chef. Os pratos apresentados são sugestões de menu e as imagens são ilustrativas.
